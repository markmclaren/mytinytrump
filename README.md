# My Tiny Trump

This is a small, static character-sprite preview featuring a generated transparent Donald Trump figure in a blue suit and red tie, posed with both arms held outward. The visual stage uses a bright upper field and a black reflective floor to make it easy to judge the asset’s silhouette and alpha edge.

## Files

| Path | Purpose |
| --- | --- |
| `images/trump.png` | Alpha-enabled full-body character asset derived from the supplied image. |
| `index.html` | Minimal browser preview of the character and reflection. |
| `css/styles.css` | The static composition and reflection styling. |
| `js/messages.js` | Attributed public quotations with source URLs. |
| `js/app.js` | Framework-free entrance and quote-rotation behaviour. |

## Note

This is a non-affiliated creative character study of a public figure. It is not an official Donald Trump, campaign, or organization asset.

The displayed quotations are presented as documented public statements with links to the underlying reporting or transcript source. The project does not present them as invented dialogue.
